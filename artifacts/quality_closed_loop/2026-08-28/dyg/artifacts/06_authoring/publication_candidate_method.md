## Dynamic graph encoding: how interaction sequences are represented with heterogeneous features and aligned

The intended encoding alignment projects all encoding types—node, edge, temporal, and co-occurrence—to a common dimension and concatenates them into a unified representation that captures both temporal and structural context. Within this aligned representation, routing scores are normalized before they are compared or aggregated, and a top-k selection retains the highest-scoring patches to produce a compact node embedding.

## Motivation: limitations of vanilla SSMs – they ignore irregular timespans and are vulnerable to input noise

Standard state-space models assume uniform timesteps and therefore ignore the irregular timespans that characterize real-world interaction sequences, and their state update provides no explicit mechanism to suppress unreliable or noisy transitions. These two limitations motivate the timespan-aware and noise-robust design choices that follow.

## Redesign: timespan-informed Δt and A for temporally aware forgetting

The timespan-aware forgetting stage is not yet anchored by a verified mechanism overview; the MambaTimeDelta module's forward pass and gating operations require repository confirmation before the stage can be described as a complete pipeline. The stage's intended scope is to couple the SSM step size to inter-event gaps and bound the input/output matrix gains for selective reviewing.

The intended mathematical specification of the timespan-aware forgetting stage is captured by the author-intent formula package. The time step is defined as $f(τ)$, where $f$ is a monotone-increasing function of the inter-event gap $τ$; the state transition matrix is specified as $A = $diag$(λ_1, …, λ_n)$ with $Re(λ_i) < 0$, so that the continuous-time decay factor $e^{A·Δt}$ contracts the state toward zero as the step size grows; and the input and output matrices are normalized as $B = B_{raw} / ||B_{raw}||_2$ and $C = C_{raw} / ||C_{raw}||_2$, bounding their gain. This specification is an author-intent formulation pending verification against the repository implementation of $f(τ)$ and the spectral-norm normalization of $B$ and $C$.

For a target node, the ordered first-hop neighbor events are obtained up to a prediction timestamp via a neighbor sampler that retrieves all first-hop neighbors, their associated edge IDs, and their interaction times, filtered by a robustness rate parameter. Node encoding uses raw node features; when a feature is unavailable, a zero vector is substituted. Absolute temporal encoding encodes the timespan from each interaction to the prediction time using a trainable cosine-based function. Source and destination neighbor feature tensors are concatenated along the feature dimension, stacked into a patch tensor, and mean-reduced over the patch dimension to produce compact node embeddings.

The GraphMixer component concatenates raw edge features and neighbor time-gap features along the feature dimension to form a combined representation. A weighted aggregation is computed as the mean of element-wise products of neighbor features and attention scores, producing a time-gap-aware neighbor aggregation. The output node features, looked up by node ID, are concatenated with the combined features to form the final node embedding. Contributing terms in the aggregation are combined by a sum over the neighbor sequence dimension.

Co-occurrence frequency encoding captures structural similarity by encoding the frequency of shared neighbors between the target node and each historical neighbor. The DyGFormer component computes source and destination node temporal embeddings, and contributing terms are aggregated by a sum over the sequence dimension. When the index is zero and a case-study flag is set (`i == 0 and case_study`), the embedding is treated as the initial state for the downstream SSM scan. The case-study branch (`case_study`) isolates a single interaction for diagnostic inspection of the temporal encoding pipeline.

The author-intent formula package specifies the complete parameter set for the timespan-aware SSM: $Δt = f(τ)$ links the step size to the elapsed inter-event gap, $A = $diag$(λ_1, …, λ_n)$ with $Re(λ_i) < 0$ ensures exponential state decay, and $B = B_{raw} / ||B_{raw}||_2$, $C = C_{raw} / ||C_{raw}||_2$ bound the input and output gains. Verification against the repository implementation of $f(τ)$ and the spectral-norm normalization of $B$ and $C$ remains pending.

The timespan-aware forgetting stage, once the mechanism overview is anchored, will comprise the continuous-state-space recurrence with a timespan-informed step size and bounded $B$/$C$ matrices, jointly implementing a selective reviewing mechanism that attenuates historical states proportionally to elapsed time. The MambaTimeDelta module applies a gating mechanism after the SSM scan: the scan output is multiplied element-wise with a gated projection, and the result is returned as the processed output.

## Downstream adaptation: link prediction and node classification setups, plus a note on linear computational complexity

The downstream prediction stage reads out fixed-size node embeddings from the sequential SSM output and feeds them into task-specific prediction heads. Because the SSM processes events sequentially, each interaction's hidden state is available at the moment it is encountered, and the step size Δt is set to the actual timespan between consecutive interactions. This direct coupling means the model handles variable-rate event sequences without requiring a uniform temporal discretization. The readout architecture applies MEAN pooling over the sequence (time) dimension to collapse the per-timestep hidden states into a single fixed-size vector, which is then passed through a multi-layer perceptron (MLP) that produces either a scalar link-prediction score or a class probability distribution for node classification, depending on the downstream task.

For link prediction specifically, two independent encoders produce source and destination node embeddings. Each embedding is pooled over the sequence dimension and the two pooled vectors are concatenated into a single vector before the MLP outputs a probability. The edge encoding stage feeds raw edge features into the link-prediction pipeline; when an edge feature is unavailable for a given interaction, a zero vector is substituted so that the encoding remains well-defined without introducing spurious signal. The EdgeBank module maintains a memory of observed edges, and at prediction time it checks whether a candidate pair satisfies `(src_node_id, dst_node_id) in edge_memories` to determine whether the link has already been observed. The edge memory is computed by one of three strategies: a repeat-threshold memory that filters by interaction frequency, a time-window memory that restricts to a configurable temporal proportion, or an unlimited memory that uses the full history. The link-prediction function accepts a set of positive edges and a set of negative edges, and for each set it computes link probabilities using the shared edge-memory tensor, writing out positive probabilities and negative probabilities as its outputs.

For node classification, a single encoder without the co-occurrence channel produces a node embedding that is passed through a classification head. This setup is intended to produce a class probability distribution whose dimensionality matches the number of target classes. The overall computation scales linearly with the number of interactions in the input sequence: the SSM processes each event in constant time, and the downstream readout operates on the resulting fixed-size representations, so neither the pooling nor the MLP introduces a super-linear dependence on sequence length.

## Robust selective reviewing

The FilterLayer forward pass aggregates contributing terms by a weighted sum of the input tensor and the hidden states, producing a filtered output that reinforces important interactions while suppressing noise. This input-dependent filtering of historical information enables robust selective reviewing: the operator modulates the contribution of each historical state according to its relevance to the current prediction context. To prevent the filtering operation from amplifying noise beyond a controlled threshold when the projection matrices are made input-dependent, the design enforces the spectral norm constraints ∥W_B∥₂ ≤ 1 and ∥W_C∥₂ ≤ 1, bounding the operator norm of B and C and ensuring stability of the learned gate.

The DyG-Mamba core replaces the standard discrete state-space model with a continuous formulation tailored to irregular interaction sequences. The step size Δt is redefined as a function of the interaction timespan so that larger gaps between consecutive interactions induce stronger state decay, implementing a timespan-aware forgetting mechanism. The state transition matrix A is initialized as a stable diagonal with eigenvalues of negative real part, guaranteeing bounded state evolution. The input and output projection matrices B and C are made input-dependent and constrained via spectral norm to limit sensitivity to noisy transitions, providing noise-robust reviewing of the interaction history.

The combined effect of the timespan-dependent step size, the stable diagonal initialization of A, and the spectrally norm-constrained input-dependent matrices B and C yields a filtering operation whose gain is controlled by the interaction timespan and whose sensitivity to individual noisy transitions is bounded. This configuration ensures that the reviewing stage reinforces temporally proximate and contextually relevant interactions while attenuating the contribution of stale or noisy historical states.
