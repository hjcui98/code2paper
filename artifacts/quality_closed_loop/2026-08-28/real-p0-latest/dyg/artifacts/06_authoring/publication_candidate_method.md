## Dynamic graph encoding: how interaction sequences are represented with heterogeneous features and aligned

The encoding pipeline produces two node embeddings per prediction event. Padded multi-channel data for the source sequence—comprising node identifiers, edge identifiers, and neighbor interaction times—are stacked along a new dimension to form a three-dimensional tensor; the same stacking operation is applied to the destination sequence, producing a corresponding tensor. A learned router computes per-patch logits for each sequence; these scores are normalized before they are compared or aggregated, yielding routing weights that sum to one over the sequence dimension. A top-k selection retains the k highest-scoring patches, and a weighted sum over the selected patches produces a compact node embedding for each sequence. The pipeline returns source and destination node embeddings as its output.

Routing weights are computed by applying softmax normalization to the router logits along the sequence dimension, producing a probability distribution over patches. The normalized weights select and aggregate patch representations, yielding a fixed-size embedding that summarizes the interaction sequence. The encoding operates over a feature space of dimension `num_channels` × `channel_embedding_dim`, where each channel corresponds to a distinct feature type. Encoding alignment is intended to project all encoding types to a common dimension and concatenate them into a unified representation, so that heterogeneous feature channels—node identity, edge attributes, absolute timestamps, and co-occurrence indicators—are expressed in a shared feature space before entering the sequential model. Co-occurrence frequency encoding is intended to serve as a lightweight structural feature channel that captures the frequency with which node pairs interact. For link prediction, two independent encoder instances process the source and destination sequences separately; their outputs are pooled, concatenated, and passed through a multilayer perceptron predictor. The encoding pipeline maps raw heterogeneous interaction data into a fixed-size embedding that preserves temporal ordering and structural context. The routing-based aggregation over selected patches ensures that the downstream sequential model receives a compact, information-rich input that reflects both the identity of interacting entities and the timing of their interactions.

## Motivation: limitations of vanilla SSMs – they ignore irregular timespans and are vulnerable to input noise

Two limitations of vanilla state-space models when applied to dynamic graphs motivate the design that follows. First, standard SSMs assume uniform timesteps and therefore ignore the irregular timespans that characterize real-world interaction sequences; second, the state update in a vanilla SSM lacks an explicit mechanism to suppress unreliable or noisy transitions, leaving the model vulnerable to input noise.

## Robust selective reviewing

The FilterLayer operates on the SSM hidden states to perform input-dependent filtering of historical interaction information. Its forward pass computes a weighted sum in which the input tensor is multiplied by a learned weight and the resulting terms are aggregated by a sum, producing a filtered representation that modulates the contribution of each historical state to the current prediction context. This aggregation constitutes the selective reviewing mechanism: the learned weighting reinforces the contribution of informative interactions while attenuating less relevant components of the interaction history. The intended design further specifies that the input-dependent projection matrices $B$ and $C$ are constrained by spectral norm bounds (W_B_2 $, W_C_2 $) to maintain stability, and that the continuous state-space formulation redefines the step size $t$ as a function of the inter-interaction timespan with the state transition matrix $A$ initialized as a stable diagonal; these specifications remain pending formal derivation and repository confirmation.

The DyG-Mamba SSM core replaces the standard discrete state-space model with a continuous formulation tailored to irregular interaction sequences. The step size is made timespan-dependent so that larger gaps between consecutive interactions induce stronger state decay, implementing a timespan-aware forgetting mechanism. The state transition matrix is initialized as a stable diagonal with eigenvalues having negative real parts, ensuring bounded state evolution. The input and output projection matrices are made input-dependent and intended to be constrained via spectral norm to limit sensitivity to noisy transitions, providing noise-robust reviewing of the interaction history.

The FilterLayer's weighted-sum aggregation over the SSM hidden states, combined with the timespan-dependent step size and stable diagonal initialization of the state transition matrix, constitutes the robust selective reviewing stage: input-dependent filtering reinforces important interactions and suppresses noise while the continuous formulation handles irregular interaction timing without explicit sequence alignment.
