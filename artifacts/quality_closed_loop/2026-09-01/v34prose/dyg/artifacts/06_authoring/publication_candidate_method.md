## Dynamic graph encoding: how interaction sequences are represented with heterogeneous features and aligned

The method extracts the first-hop interaction sequence of a node and encodes it through heterogeneous signals—node identity, edge type, absolute temporal, and co-occurrence—by passing the aligned sequence through a continuous selective state-space model, transforming raw interaction sequences into a unified feature representation that captures both temporal and structural context. Sequences are padded to a fixed maximum length and stacked along a channel dimension whose size is the product of the number of channels and the per-channel embedding dimension, yielding a multi-channel tensor for both source and destination nodes. Softmax-normalized routing weights are then computed over the channel axis; for the destination representation, a top-k selection retains the most salient channel embeddings, while the source representation is obtained by a weighted reduction of its channel embeddings using the same routing weights. The resulting source and destination node embeddings are returned as the aligned output of the encoding stage.

## Motivation: limitations of vanilla SSMs – they ignore irregular timespans and are vulnerable to input noise

Vanilla state-space models assume a uniform sampling interval and therefore cannot represent the variable time gaps that arise in real-world irregularly sampled data. In addition, the fixed-parameter state update of a vanilla SSM is sensitive to input noise, which degrades the quality of the learned state trajectory under noisy observations.

## Redesign: timespan-informed Δt and A for temporally aware forgetting

The SSM forgets historical states proportionally to elapsed time by expressing Δt as a function of the timespan and initializing A with strictly negative real-part eigenvalues to ensure stable decay. Interaction sequences are extracted as the ordered first-hop neighbor events for a target node up to a prediction timestamp. Node representations use raw node features, with zero vectors substituted when features are unavailable. Timespans from each interaction to the prediction time are encoded via a trainable cosine-based positional function. When the temporal Mamba branch is active (`self.time_mamba and dts != None`), hidden states are rearranged through a projection weight and the transformed output is returned. In the case-study configuration (`i == 0 and case_study`), source-patch node features and neighbor raw features are concatenated to form the input representation.

Structural similarity between the target node and each historical neighbor is captured by encoding the frequency of shared neighbors, which serves as a co-occurrence frequency signal. The redesign redefines B and C with a spectral-norm constraint to promote robust selective reviewing, while Δt and A are shaped by the timespan so that forgetting is temporally aware. The matrix A is initialized as a diagonal matrix whose eigenvalues have strictly negative real parts, guaranteeing bounded state decay. In the case-study configuration (`i == 0 and case_study`), occurrence-frequency features of the source patches and neighbor nodes are concatenated with the destination representation.

## Downstream adaptation: link prediction and node classification setups, plus a note on linear computational complexity

Downstream prediction reads out fixed-size node embeddings from the sequential output and produces task-specific predictions via MEAN pooling over the sequence dimension followed by an MLP head for link prediction or node classification. Edge encoding uses raw edge features, substituting zero vectors when features are unavailable. The SSM step size Δt is directly coupled to the irregular timespans between interactions. Edge memories are written for each observed interaction, and link probabilities are predicted from the edge-memory tuple together with a negative sample. When (src_node_id, dst_node_id) in edge_memories, the edge bank retrieves the unlimited-memory history for the source node, branches on the condition, and returns an array of probabilities for the candidate pair.

## Robust selective reviewing

The DyG-Mamba SSM core implements a continuous state space model with a redefined timespan-dependent step size Δt and a stable diagonal initialization of A, enabling input-dependent filtering of historical information so that important interactions are reinforced and noise is suppressed. The hidden states are computed from the input tensor through the weight transformation and returned as the selective review output. When temporal step information is available, the timespan-dependent step size modulates the filtering to reflect the span between consecutive interactions. The selective reviewing mechanism is designed to maintain stability through spectral norm constraints on the input-dependent projection matrices, ensuring that the filtering remains well-conditioned.

The input-dependent matrices B and C are made to depend on the input through the same selective reviewing pathway, and their spectral norms are constrained to satisfy ∥W_B∥₂ ≤ 1 and ∥W_C∥₂ ≤ 1, implementing timespan-aware forgetting and noise-robust reviewing.
