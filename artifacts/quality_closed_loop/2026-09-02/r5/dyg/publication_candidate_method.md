## Dynamic graph encoding: how interaction sequences are represented with heterogeneous features and aligned

The model extracts first-hop interaction sequences for source and destination nodes, padding them to a uniform sequence length $L_{\text{src}}$ so that heterogeneous features—node identity, edge attributes, absolute temporal context, and co-occurrence signals—are embedded independently and stacked into a unified feature vector per interaction. A routing mechanism computes softmax weights over the sequence dimension; for the source node all weights are retained, while for the destination node only the top-$k$ weights are kept, bounded by $\text{min}(k, L_{\text{dst}})$. The final node embeddings are obtained as a weighted sum of the aligned feature vectors: $$
\begin{aligned} \mathbf{E}_{\text{src}} &= \sum_{i=1}^{L_{\text{src}}} \alpha_{\text{src},i} \cdot \mathbf{h}_{\text{src},i} \\ \mathbf{E}_{\text{dst}} &= \sum_{j=1}^{k} \alpha_{\text{dst},j} \cdot \mathbf{h}_{\text{dst},j} \end{aligned}
$$ where $	heta_{\text{src},i}$ and $	heta_{\text{dst},j}$ denote the routing weights for the $i$-th source interaction and the $j$-th selected destination interaction, $\text{h}_{\text{src},i}$ and $\text{h}_{\text{dst},j}$ are the aligned, stacked feature vectors, and $k$ is the number of top interactions selected for the destination node.

## Motivation: limitations of vanilla SSMs – they ignore irregular timespans and are vulnerable to input noise

Standard SSMs operate on uniformly sampled sequences and lack an explicit mechanism for handling irregular inter-event intervals or suppressing noisy transitions.

## Redesign: timespan-informed Δt and A for temporally aware forgetting

The timespan-aware forgetting mechanism decouples the discrete time step $Δt$ from input features and instead derives it as a function of the elapsed timespan $τ$ between the interaction and the prediction time, so that the state-space model forgets historical states proportionally to elapsed duration. The state transition matrix $A$ is initialized as $A_0$ with stable decay properties, ensuring that the hidden state decays smoothly over time rather than depending on input-driven gating. The input matrix $B$ and output matrix $C$ are redefined as $B_{\text{spec}}$ and $C_{\text{spec}}$ with spectral-norm constraints, which supports robust selective reviewing by bounding the per-interaction contribution to the state update. For temporal encoding, timespans from each interaction to the prediction time are mapped through a trainable cosine-based function, and node representations are obtained from raw features with zero vectors substituted when features are unavailable. The ordered first-hop neighbor events for a target node are extracted up to a prediction timestamp, providing the temporal sequence over which the SSM recurrence operates. The combined mechanism is formalized as $$
\Delta t = f_{\Delta t}(\tau), \quad A = A_0, \quad B = B_{\text{spec}}, \quad C = C_{\text{spec}}
$$, where $f_{Δt}$ denotes the mapping from timespan to step size and $A_0$ encodes the stable-decay initialization of the state transition matrix.

Co-occurrence frequency encoding captures structural similarity by measuring the frequency of shared neighbors between the target node and each historical neighbor, providing a structural prior that complements the timespan-driven forgetting. The redesign formalizes the timespan-informed mechanism by deriving $Δt$ from the timespan $τ$ via a trainable function $f_{\text{time}}$, initializing the diagonal state transition matrix $A$ with eigenvalues $λ_i$ satisfying $\text{Re}(λ_i) < 0$ for stable decay, and constraining the input and output matrices $B$ and $C$ to unit spectral norm for robust selective reviewing. The complete redesign is expressed as $$
\Delta t = f_{\text{time}}(\tau), \quad A = \text{diag}(\lambda_1, \dots, \lambda_n), \quad \text{Re}(\lambda_i) < 0, \quad \|B\|_2 = \|C\|_2 = 1
$$, where $f_{\text{time}}$ maps the elapsed timespan to the discrete step size and the spectral-norm constraint on $B$ and $C$ bounds the per-interaction contribution to the state update.

## Downstream adaptation: link prediction and node classification setups, plus a note on linear computational complexity

Downstream prediction is realized by reading out fixed-size node embeddings from the sequential output and passing them through a task-specific predictor. For edge encoding, raw edge features are used directly, with zero vectors substituted where features are unavailable. The readout stage applies mean pooling over the sequence dimension to produce a fixed-size representation, which is then fed to a multilayer perceptron for link prediction or node classification. The SSM step size Δt is set equal to the irregular timespan between consecutive interactions, so that the continuous-time dynamics are discretized at the native temporal granularity of the observed event sequence.
