# 当前任务记录

本目录用于 Codex 的可选、简短任务笔记。Codex 直接承担实现和验证，不依赖其他工具的交接或验收指令。

## 使用方式

- 普通修改直接执行并在交付中说明，无需维护固定的四份交接文件。
- 持续多轮的任务可创建一份任务笔记，记录目标、当前代码状态、已完成工作、验证和下一步；保持更新，不叠加互相矛盾的历史指令。
- 持久设计和诊断报告放入 `docs/`，冻结运行证据按仓库产物约定保存。
- 已完成的任务笔记及时清理；历史事实通过 Git 和冻结产物查阅。
- 本目录记录补充当前用户任务，不覆盖 `AGENTS.md` 或当前会话的明确要求。
