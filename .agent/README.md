# Codex 本地工作记录

自 2026-09-12 起，本仓库由 Codex 直接完成诊断、规划、实现、测试、审查和修复。
协作规则见 [AGENTS.md](../AGENTS.md)，设计与执行文档入口见 [docs/README.md](../docs/README.md)。

- 当前任务以用户请求为准，不自动接续旧任务、旧 REPAIR 或历史运行计划。
- 小改动直接实施并报告结果，不要求建立 task/plan/review 四件套。
- 较大任务可在 [implementation.md](implementation.md) 记录范围、关键决策、修改、验证和剩余问题。
  需要长期维护的设计、计划与证据报告放在 `docs/`，不要在这里复制一套权威文档。
- 测试记录写明命令、退出码、行为结果和对应代码状态；真实运行还应绑定配置、模型与产物目录。
  不把历史通过结论当成当前验证，也不因记录迁移而关闭未解决的问题。
